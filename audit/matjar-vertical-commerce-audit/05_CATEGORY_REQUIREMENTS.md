# 05 — مواصفات المتطلّبات على مستوى الحقول (Master Field-Level Requirements)

هذا المستند المرجعي لكلّ القطاعات السبعة عشر. الملفّات العموديّة (06–15) تُحيل إليه ولا تُكرّره. لكلّ قطاع: **نموذج التعامل الصحيح (A–L)**، **حقول onboarding التاجر**، **حقول نموذج المنتج/الخدمة (مطلوب + اختياري)**، **هرم صفحة التفاصيل**، **الـCTA الأساسي والثانوي**، **خطوات التعامل**، **مسار الحالة**، ثمّ **الحدّ الأدنى للنشر** و**الملفّ الكامل**.

## مفتاح نماذج التعامل (A–L) وحالتها في مطجر
| رمز | النموذج | الحالة في مطجر (من الأدلّة) |
|---|---|---|
| A | شراء مباشر Direct purchase | ✅ ناضج (orders/order_items/cart/zones 0172) — COD فقط |
| B | طلب طعام Food order | ⚠️ = A فعليًّا؛ لا modifier groups مطلوبة، لا ملاحظة بند، لا جدولة |
| C | موعد Appointment | ✅ محرّك ناضج `place_booking` (0174) لكنه **مقيّد UI لـ {services, healthcare, realEstate}** |
| D | إقامة بمدى تاريخي Accommodation | ❌ غائب — bookings تحمل span واحد ≤8h، لا check-in/out |
| E | حجز طاولة Table reservation | ✅ ReservationForm (تاريخ+وقت+party_size) |
| F | طلب خدمة Service request | ⚠️ service_requests بلا صور/إلحاح/نطاق/إسناد/تتبّع |
| G | عرض سعر Quotation | ⚠️ quote_amount/quote_note بلا brief منظّم (نطاق/ميزانية/مهلة/ملفّات) |
| H | Lead/استعلام | ❌ غائب — لا جدول leads/inquiries/viewings |
| I | قائمة عقار Property listing | ⚠️ products.attributes jsonb فقط؛ لا viewing/agent/خريطة/نطاقات |
| J | قائمة مركبة Vehicle listing | ❌ خطأ — automotive = commerce → add-to-cart COD |
| K | تذكرة/فعالية Ticket/event | ❌ غائب — TimeslotBooking بالساعة |
| L | عضويّة/اشتراك Membership | ❌ معلن فقط — بطاقات سعر + WhatsApp، لا صفّ في DB |

## 1. food — مطاعم ومأكولات (commerce/menu)
**النموذج الصحيح:** B أساسي + E (حجز طاولة) + A (منتجات تُباع بالقطعة). حاليًّا B=A بلا modifiers.

| البند | المطلوب |
|---|---|
| Onboarding التاجر | اسم، slug، business_type، منطقة/area، phone، whatsapp، وصف + **نوع المطبخ**، **مناطق التوصيل + رسوم/حدّ أدنى**، **وقت التحضير**، **ساعات العمل**، **حدّ أدنى للطلب**، delivery/pickup toggle |
| نموذج الصنف — مطلوب | الاسم (ar/en)، السعر، القسم/الفئة، صورة، حالة التوفّر |
| نموذج الصنف — اختياري | وصف، سعرات، **مجموعات إضافات (modifier groups: الاسم، required?، min/max، خيارات باسم+سعر)**، وسوم (حار/نباتي/حلال)، **ملاحظة بند**، مقاسات، مكوّنات/مسبّبات حساسيّة، وقت تحضير للصنف |
| هرم صفحة التفاصيل | صورة → الاسم+السعر → الوصف/السعرات → **مجموعات الإضافات المطلوبة** → ملاحظة → توفّر/وقت تحضير → أضف للسلّة |
| CTA أساسي / ثانوي | «أضف إلى الطلب» / «احجز طاولة» + «واتساب المطعم» |
| خطوات التعامل | تصفّح قائمة → اختيار صنف + إضافات مطلوبة → سلّة → منطقة توصيل + فكّة (change_for) → **وقت الآن/مجدول** → تأكيد COD → المطبخ يقبل |
| مسار الحالة | pending → accepted (kitchen) → preparing → out_for_delivery / ready_pickup → completed / cancelled |
| الحدّ الأدنى للنشر | اسم مطعم + منطقة + phone + صنف واحد بسعر + منطقة توصيل واحدة |
| الملفّ الكامل | ساعات، مناطق توصيل كاملة برسوم/ETA، قائمة مقسّمة بأقسام، صور لكلّ صنف، modifier groups، حجز طاولة مُفعّل، شارة توثيق |

**النموذج الصحيح:** A. هذا هو المسار الناضج فعلًا.

| البند | المطلوب |
|---|---|
| Onboarding | القياسي + مناطق توصيل + سياسة إرجاع + توثيق تجاري |
| نموذج المنتج — مطلوب | الاسم (ar/en)، السعر، صورة، مخزون، قسم |

| هرم التفاصيل | معرض → الاسم+الماركة → السعر/الخصم → **منتقي المتغيّرات (لون ثم مقاس)** → المخزون → الوصف → أضف للسلّة → مراجعات → منتجات ذات صلة |

| الملفّ الكامل | أقسام، متغيّرات كاملة، مناطق توصيل، سياسة إرجاع، توثيق، مراجعات مُفعّلة |

## 3. services — خدمات عامّة (booking/services)
**النموذج الصحيح:** C (موعد) للخدمات المجدولة + F/G (طلب/عرض سعر) للخدمات المفتوحة. المحرّك C متوفّر لهذا القطاع فعلًا.

| البند | المطلوب |
|---|---|
| Onboarding | القياسي + **مزوّدون (providers/doctors) بساعات عمل**، مدّة الفتحة booking_slot_minutes، ساعة الإلغاء booking_cancel_hours |
| نموذج الخدمة — مطلوب | الاسم، السعر، **المدّة (دقائق)**، allocation_mode، المزوّد (إن وُجد) |
| نموذج الخدمة — اختياري | buffer_minutes، capacity_per_slot، وصف، متطلّبات مسبقة، سعر «يبدأ من»، نطاق خدمة/تنقّل |
| هرم التفاصيل | الاسم → السعر+المدّة → الوصف → **اختيار المزوّد** → **تقويم فتحات صالحة** → السياسات → احجز |
| CTA أساسي / ثانوي | «احجز موعدًا» / «اطلب عرض سعر» + «واتساب» |
| خطوات التعامل | خدمة → مزوّد → **فتحة صالحة (منع تعارض GiST)** → بيانات → تأكيد → التاجر يقبل → تذكير → حضور |
| مسار الحالة | pending → accepted/scheduled → completed / cancelled / no_show |
| الحدّ الأدنى للنشر | اسم + منطقة + phone + خدمة بمدّة وسعر + ساعات مزوّد واحد |
| الملفّ الكامل | مزوّدون بصور وساعات واستثناءات، coupons، سياسة إلغاء، تذكيرات، قائمة انتظار |

## 5. realEstate — عقارات (booking/listings)
**النموذج الصحيح:** I (قائمة عقار) + H (lead/طلب معاينة). حاليًّا يُعامَل كموعد (BookingPanel فتحة واحدة) بلا lead — **خطأ بنيوي**.

| البند | المطلوب |
|---|---|
| Onboarding | القياسي + **وكلاء (agents)**، نوع الوكالة، مناطق التغطية |
| نموذج القائمة — مطلوب | العنوان، **purpose (بيع/إيجار)**، **ptype (شقة/منزل/أرض/مكتب/محلّ/شاليه)**، السعر، **المنطقة + خريطة (lat/lng)**، **المساحة m²**، الغرف، الحمّامات |
| — اختياري | مؤثّث (yes/no)، الطابق، عمر البناء، مفروشات/خدمات، معرض صور/فيديو، الوكيل المسؤول، رسوم، متاح-من |
| هرم التفاصيل | معرض → العنوان+السعر → purpose/ptype/غرف/حمّامات/مساحة → **خريطة موقع** → الوصف/المرافق → **الوكيل** → **اطلب معاينة/تواصل** |
| CTA أساسي / ثانوي | «اطلب معاينة» (ينشئ lead) / «تواصل مع الوكيل» + «واتساب» |
| خطوات التعامل | بحث (نطاق سعر/غرف/منطقة على الخريطة) → قائمة → **طلب معاينة (اسم/هاتف/وقت مفضّل)** → **lead يُنشأ** → الوكيل يتابع → مُعايَن/مُغلَق |
| مسار الحالة (lead) | new → contacted → viewing_scheduled → offer → closed_won / closed_lost |
| الحدّ الأدنى للنشر | عنوان + purpose + ptype + سعر + منطقة + صورة + هاتف تواصل |
| الملفّ الكامل | خريطة، مساحة/غرف/حمّامات، معرض، وكيل مُسنَد، فلاتر نطاقيّة، صندوق leads |

## 6. automotive — سيارات ونقل (commerce/listings)
**النموذج الصحيح:** J (قائمة مركبة) + H (lead/تجربة قيادة) للبيع؛ + D (مدى تاريخي) للتأجير. حاليًّا commerce → «شراء سيّارة بالدفع عند التسليم» — **خطأ صريح**.

| البند | المطلوب |
|---|---|
| Onboarding | القياسي + نوع المعرض (بيع/تأجير)، مناطق |
| نموذج القائمة — مطلوب | **brand، model، year، السعر، condition (جديد/مستعمل)**، صور |
| — اختياري | mileage km، gearbox، fuel، لون، رقم أبواب، ضمان، **وضع التأجير + سعر/يوم + تقويم إتاحة** |
| هرم التفاصيل | معرض → brand/model/year+السعر → mileage/gearbox/fuel/condition → الوصف → **تواصل/احجز تجربة قيادة** (بيع) أو **اختر مدى تواريخ** (تأجير) |
| CTA أساسي / ثانوي | بيع: «تواصل/احجز تجربة قيادة» (lead) — تأجير: «تحقّق من التوفّر واحجز» / «واتساب» |
| خطوات التعامل (بيع) | فلترة (brand/year/سعر نطاق) → قائمة → lead تجربة قيادة → المعرض يتابع |
| خطوات التعامل (تأجير) | فلترة → مركبة → **مدى تواريخ (منع تداخل)** → السعر الكلّي → طلب → تأكيد |
| مسار الحالة (lead) | new → contacted → test_drive → negotiation → closed |
| الحدّ الأدنى للنشر | brand + model + year + سعر + condition + صورة + هاتف |
| الملفّ الكامل | مواصفات كاملة، معرض، وضع بيع/تأجير واضح، صندوق leads، تقويم تأجير |

| — اختياري | صورة، وصف، مقاعد مخصّصة، باقات، حدّ لكلّ مشترٍ، خدمات إضافيّة |
| هرم التفاصيل | العنوان+التاريخ+المكان → أنواع التذاكر+الأسعار → **اختر النوع+الكميّة (سعة متبقّية)** → الإجمالي → احجز/اشترِ تذكرة |
| CTA أساسي / ثانوي | «احجز تذكرة» / «احجز القاعة» + «واتساب» |
| خطوات التعامل | فعالية → نوع تذكرة → كميّة (≤ المتبقّي) → بيانات الحضور → تأكيد → تذكرة/رمز |
| مسار الحالة | pending → confirmed → attended / cancelled / refunded |
| الحدّ الأدنى للنشر | عنوان + تاريخ + مكان + نوع تذكرة واحد بسعر وسعة |
| الملفّ الكامل | أنواع تذاكر متعدّدة بسعة، حدّ لكلّ مشترٍ، رموز حضور، حجز قاعة منفصل |

## 12. hospitality — فنادق وشاليهات (booking/services)
**النموذج الصحيح:** D (إقامة بمدى تاريخي). حاليًّا TimeslotBooking بالساعة — **يستحيل التعبير عن إقامة**. الفجوة الأكبر في المنصّة.

| البند | المطلوب |
|---|---|
| Onboarding | القياسي + **العقارات/الوحدات (properties/units)**، سياسة check-in/out، سياسة إلغاء |
| نموذج الوحدة — مطلوب | الاسم، النوع (غرفة/شاليه/شقة)، **السعة (بالغين/أطفال)**، **السعر/ليلة**، عدد الوحدات المتاحة |
| — اختياري | **تسعير موسمي/عطلة نهاية أسبوع**، **حدّ أدنى للّيالي (min-stay)**، **رسوم تنظيف**، تأمين، مرافق (مسبح/واي فاي)، معرض، سياسة حيوانات، وقت check-in/out |
| هرم التفاصيل | معرض → الاسم+السعر/ليلة → **منتقي check-in/check-out** → السعة (بالغين/أطفال) → **تقويم إتاحة (أيّام محجوزة معطّلة)** → المرافق → **السعر الكلّي (ليالٍ×سعر + تنظيف)** → السياسات → اطلب حجزًا |
| CTA أساسي / ثانوي | «تحقّق من التوفّر واحجز» / «واتساب» |
| خطوات التعامل | بحث بتواريخ+ضيوف → وحدة متاحة → **مدى تواريخ (منع تداخل + min-stay)** → **سعر بعطلة/موسم + رسوم تنظيف** → طلب → **التاجر يؤكّد** → check-in → check-out → مكتمل |
| مسار الحالة | pending → confirmed → checked_in → checked_out → completed / cancelled (حسب السياسة) |
| الحدّ الأدنى للنشر | اسم + منطقة + phone + وحدة بسعة وسعر/ليلة + سياسة check-in/out |
| الملفّ الكامل | وحدات متعدّدة، تقويم إتاحة، تسعير موسمي/عطلة، min-stay، رسوم تنظيف، صور، سياسة إلغاء |

| هرم التفاصيل | صورة → الاسم+السعر → يتطلّب وصفة؟ → المخزون → أضف للسلّة / **ارفع وصفة** |

| البند | المطلوب |
