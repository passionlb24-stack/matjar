# 19 — متطلّبات لوحة تحكّم التاجر لكلّ قطاع (Per-Sector Merchant Dashboard)

## الوضع الحالي (من الأدلّة)
لوحة الـOS مبنيّة على **وحدات config-driven** (`src/lib/sectors.ts` + `modules-catalog.ts`: 22 وحدة بـ tier وdependsOn) مع بوّابة خطط (`store_modules`: enabled + config jsonb **غير مُستخدَم**). البوّابات: pos/reports/coupons/customers/doctors/staff/tasks/tools = **pro** ؛ inventory/suppliers/kitchen/branches/automations/campaigns/accounting = **business**.

**المشكلة الجوهريّة:** الوحدات موجودة لكنها **بمفردات عامّة لا قطاعيّة**. الفندق يرى «حجوزات» عامّة بدل **تقويم إتاحة/أسعار**؛ العقارات لا ترى **صندوق leads**؛ اللياقة لا ترى **سجلّ عضويّات**؛ المطعم لا يرى **شاشة مطبخ/modifiers**. الوحدة تُعرَض فقط إن وُجدت صفوف (data-presence gating) → وحدة مُفعّلة بلا بذور = فراغ بلا تغذية راجعة للتاجر.

**المطلوب:** كلّ لوحة قطاع تُظهر الوحدات بالمفردات والأدوات الصحيحة، وتُخفي غير المتعلّق. الجداول أدناه: **✅ يجب أن تظهر** / **➕ يجب بناؤه (غير موجود)** / **🚫 يُخفى (غير متعلّق)**.
